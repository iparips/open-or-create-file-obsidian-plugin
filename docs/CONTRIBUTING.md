## Development

This project uses [Bun](https://bun.sh/) for TypeScript development, which simplifies the setup process compared to traditional Node.js + TypeScript configurations.

### Setup

1. Install Bun
2. Clone this repository
3. Run `bun install` to install dependencies
4. Run `bun run build` to build the plugin
5. Soft link the repo to obsidian plugins directory, eg:

```
ln -s /Users/ilya/Code/open-or-create-file-obsidian-plugin /Users/ilya/ObsidianVault23/Personal/.obsidian/plugins/open-or-create-file-obsidian-plugin
```
